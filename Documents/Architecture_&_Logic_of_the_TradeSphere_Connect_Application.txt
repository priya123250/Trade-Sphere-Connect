1. File Handling and Data Management

Safe CSV Reading (safe_read_csv())

def safe_read_csv(file_path, columns):
    if os.path.exists(file_path):
        try:
            df = pd.read_csv(file_path)
            if df.empty:
                return pd.DataFrame(columns=columns)
            return df
        except (pd.errors.EmptyDataError, ValueError):
            return pd.DataFrame(columns=columns)
    return pd.DataFrame(columns=columns)

Low-Level Operations:
- os.path.exists() checks the file system
- pd.read_csv() performs file I/O and parsing
- Exception handling covers empty or malformed data
