# 🌐 TradeSphere Connect

TradeSphere Connect is a supplier evaluation and decision-making platform built using Streamlit. It allows internal company officers to review, assess, and track supplier applications based on various business criteria and needs.

## 📌 Features

- 🔐 Auto-login for internal demo use
- 📋 Review supplier applications using scoring logic
- 🧠 Intelligent decision engine (Approve / Approve with Conditions / Reject)
- 📊 Interactive metrics dashboard using Plotly
- 🔍 Application filtering by country, rating, and decision
- ✅ Pre-loaded demo applications for demonstration
- 🗃️ Persistent data storage via CSV

## 🏁 Getting Started

1. **Install Dependencies**  
   Use the `requirements.txt` file to install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the App**
   ```bash
   streamlit run TS_CONNECT.py
   ```

3. **Interact with the App**  
   Navigate through:
   - 🏠 Dashboard  
   - 📋 Applications  
   - 📄 Review Application  
   - 📊 Analytics

## 🧠 Decision Logic

The decision engine uses a weighted scoring method based on:
- Supplier rating
- Current needs
- Trading history or recommendation
